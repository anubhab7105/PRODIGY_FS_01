# 🔐 Secure User Authentication System

A responsive and secure authentication system with login/registration functionality, built with Python Flask and modern frontend technologies. Features password hashing, session management, and protected routes.

## ✨ Features
- User registration with secure password hashing
- Session-based authentication
- Protected routes for authenticated users only
- Responsive design (works on both desktop and mobile)
- Password validation (minimum 6 characters)
- Popup notifications for errors/success
- SQLite database for user storage
- Modern UI with gradient design and animations

## 🛠️ Technologies
- **Backend**: Python (Flask, Werkzeug, SQLite3)
- **Frontend**: HTML5, CSS3, JavaScript
- **Security**: Password hashing, session management
